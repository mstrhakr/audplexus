# Audplexus User Guide

This guide is the quick-start path for normal day-to-day use. It is meant to help you do the most important tasks without reading the whole app architecture.

## Recommended order

If this is your first time using Audplexus, follow these in order:

1. [Getting Started](./getting-started.md) — first run, login, and basic setup
2. [Connect a Library Destination](./connect-library-destination.md) — send books to Plex, Emby, Jellyfin, or Audiobookshelf
3. [Sync Your Library](./sync-library.md) — refresh Audible metadata and file inventory
4. [Queue and Download Books](./downloads-and-queue.md) — manage the processing pipeline
5. [Output and Settings](./output-and-settings.md) — format, metadata, and behavior defaults
6. [Diagnostics and Fixes](./diagnostics-and-fixes.md) — troubleshoot missing books or failed destinations
7. [Unraid App Store Setup](./unraid-app-store.md) — special deployment guidance for Unraid installs

## Before you begin

- make sure the app is running and reachable in your browser
- connect Audible before you rely on library sync
- start with one library destination so you can validate the end-to-end flow before adding more
- keep output paths writable and stable; the most common setup problems are permissions and path mismatches
