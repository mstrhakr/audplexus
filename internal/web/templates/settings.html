Library

Choose how to organize your audiobook files.
Tokens: {author}, {author_asin}, {title}, {subtitle}, {series}, {series_position}, {asin}, {region}, {narrator}, {publisher}, {language}, {duration}, {release_date}, {purchase_date}, {drm_type}.
Use / for nested folders. Conditional segments work Sonarr-style: { - subtitle}, { [region]}, { (narrator)}.
Extension is added automatically. Keep tokens data-only and place punctuation/spaces inside conditional blocks.
Controls coverage meters on the dashboard and destination cards.

{{/* ── Tag Profile ────────────────────────────────────────────── Its own form because it persists via /settings/tag-profile, not /api/settings. Sits next to Library since it controls the atoms embedded into downloaded files. */}}

Tag Profile

Tags saved inside each file when it downloads. Audiobook-rich (default) adds series, series-part, and asin tags so apps like Audiobookshelf can group series for you. Basic leaves those out and matches how older versions tagged files. Only changes files you download from now on.
