{{/* ── Section 4: Setup help (consolidated per-type guidance) ─ */}}
Setup help Where to find tokens, API keys, and library IDs in {{.DestTypeLabel}}.
{{if eq $dt "plex"}}
Plex token
  1. Sign in to Plex web at http://<your-plex>:32400/web.
  2. Play any audiobook (or open its detail page).
  3. Click the ⋯ menu → Get Info → View XML.
  4. The new tab's URL contains ?X-Plex-Token=… — copy that value.
  5. Or see Plex's official guide.
Section ID
  1. In Plex web, click your audiobook library in the sidebar.
  2. The URL bar shows /source/<sectionId> — that number is your section ID.
  3. API alternative: curl 'http://<plex>:32400/library/sections?X-Plex-Token=…'.
{{else if eq $dt "emby"}}
API key
  1. Open Emby's web UI as an administrator.
  2. Settings (gear) → Server → Advanced → API Keys.
  3. Click + New API Key. Name it "Audplexus".
  4. Copy the generated key — Emby may show it only once.
Library ID
  1. curl 'http://<emby>:8096/emby/Library/MediaFolders?api_key=…' | jq
  2. Find the entry where CollectionType is audiobooks.
  3. Copy its ItemId.
{{else if eq $dt "jellyfin"}}
API key
  1. Open Jellyfin's web UI as an administrator.
  2. Dashboard → API Keys (under Advanced).
  3. Click +. App name "Audplexus".
  4. Copy the generated key — Jellyfin shows it once at creation.
Library ID
  1. curl -H 'Authorization: MediaBrowser Token="…"' 'http://<jellyfin>:8096/Library/VirtualFolders' | jq
  2. Find "CollectionType": "books" with an audiobook path.
  3. Copy its ItemId.
{{else if eq $dt "abs"}}
API key
  1. Open Audiobookshelf as an administrator.
  2. Settings (gear) → Users → click your admin user.
  3. Scroll to API Keys → Generate API Key. Required scope: admin.
  4. Token is shown once — copy it immediately.
Library ID
  1. curl -H 'Authorization: Bearer …' 'http://<abs>/api/libraries' | jq '.libraries[] | {id,name,mediaType}'
  2. Find mediaType = book.
  3. Copy its id (UUID).
  4. Or: open ABS web → click your audiobook library → URL /library/<id>.
{{end}}
